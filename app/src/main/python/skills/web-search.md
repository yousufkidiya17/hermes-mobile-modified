# Web Search

Use the `web_search` tool to find current information from the web.

When to use:
- User asks about current events, news, or recent facts
- User needs facts you are unsure about
- User wants to research a topic

Steps:
1. Formulate a concise search query with the key terms
2. Call `web_search` with the query
3. Review the result titles
4. Use `web_fetch` on the most relevant result to get full content

Tips:
- Keep queries short and specific
- Use quotes for exact phrases
- Combine with current knowledge for best answers
